# Smart Sip

Página demonstrativa de uma vitrine de copos Smart Sip, desenvolvida com HTML, CSS e JavaScript para praticar a construção de interfaces web.

## Tecnologias

- HTML5.
- CSS3.
- JavaScript.
- Google Fonts.

## Conteúdo

- Identidade visual e imagens dos produtos.
- Três modelos de copos, com capacidades e preços apresentados na interface.
- Botões “Comprar Agora”.

O projeto é uma demonstração de interface; não representa uma loja com pagamento ou processamento de pedidos.

## Como visualizar

1. Baixe o repositório em **Code → Download ZIP** e extraia os arquivos, ou clone:

   ```bash
   git clone https://github.com/raquelzapparolli/Smart-Sip.git
   ```

2. Abra `index.html` no navegador.

Mantenha os arquivos e imagens na mesma pasta. A fonte externa usa conexão com a internet.

## Organização

| Arquivo | Função |
| --- | --- |
| `index.html` | Estrutura da vitrine. |
| `styles.css` | Estilos da página. |
| `scripts.js` | Script da interface. |
| `*.jpeg` | Logo e imagens dos produtos. |

## Objetivo

Praticar a organização de conteúdo, estilos e scripts em uma página de produtos.
